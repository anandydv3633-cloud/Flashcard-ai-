# 📚 Flashcard AI Lab

An AI-powered flashcard generator that automatically creates educational flashcards from text using a Hugging Face model.

## 🚀 Features

- 🤖 AI-generated educational flashcards
- 📝 Generate multiple Question & Answer pairs from any text
- 🎯 Focuses on important concepts
- ⚡ Simple and lightweight Python application
- 🔐 Uses environment variables to securely store API tokens

## 🛠️ Technologies Used

- Python
- Hugging Face Inference API
- Hugging Face Hub
- Python-dotenv
- Google Flan-T5 Base
